# 고양·파주 도시계획 지도 — GitHub Pages 배포 가이드

## 폴더 구조
```
goyang-paju-site/
├── index.html
└── data/
    ├── config.json
    ├── projects.json
    └── roads.json
```

## 배포 방법 (5분)

**1단계** — github.com → `+` → `New repository` → 이름 입력 → `Public` → `Create`

**2단계** — `uploading an existing file` 클릭 → index.html + data 폴더 전체 드래그앤드롭 → `Commit changes`

**3단계** — `Settings` → `Pages` → Branch: `main` / `root` → `Save`

**4단계** — 1~2분 후 `https://[GitHub아이디].github.io/[저장소이름]` 접속

저에게 KMZ 파일 올려주시면 projects.json 업데이트해드립니다. GitHub에 해당 파일만 재업로드하면 반영됩니다.
